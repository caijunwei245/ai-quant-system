# 1. pipeline.py 审计

重点检查：

## 数据流

目标：

确认：

``` id="jajznb"
行情
 ↓
因子
 ↓
模型
 ↓
信号
 ↓
组合
 ↓
交易
```

是否存在：

- 数据重复计算
- 未来函数
- 模型输出污染
- 层之间耦合


重点搜索：

```python id="0l4fc9"
fit()
train()
predict()
transform()
```

风险：

例如：

```python id="f788ah"
processor.fit(all_data)
```

然后：

```python id="49msm1"
train/test split
```

这是典型未来数据泄漏。

正确：

``` id="u8lc0x"
train period
     |
fit scaler/factor
     |
test period
     |
transform only
```

# 2. screening.py 审计（最高优先级）

README 中说明：

> LightGBM 负责全市场因子选股，预测未来5日涨跌

fileciteturn0file0


重点检查：

---

## Label 构造

寻找：

```python id="p6dkny"
future_return
```

或者：

```python id="5pi5ff"
shift(-5)
```

检查：

是否：

```python id="t6hcjs"

df.close.shift(-5)>df.close
```

如果是：

问题：

- 没处理停牌
- 没处理涨跌停
- 没处理复权
- 没处理交易日

---

## 特征泄漏

检查：

危险：

```python id="ui5ii3"
rolling()
mean()
std()
```

是否：

缺少：

```python id="33f66i"
shift(1)
```

例如：

错误：

```python id="gvn7id"
df["ma20"]=
df.close.rolling(20).mean()
```

如果当天收盘后交易：

可以。

如果盘中：

泄漏。


---

## 模型训练

检查：

是否：

```python id="mqds2l"

```

严重问题。

应该：

```python id="yinlel"
TimeSeriesSplit
```

Walk Forward。
